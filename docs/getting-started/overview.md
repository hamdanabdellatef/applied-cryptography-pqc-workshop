# Workshop overview

**Audience:** developers, security and DevSecOps engineers, architects, and technical leads.

**Level:** intermediate; practical programming experience, no advanced mathematics required.

**Format:** three instructor-led days, six Python labs, and a team architecture capstone. A condensed two-day route will follow after the full course is timed.

Participants will learn to select and integrate established cryptographic mechanisms, diagnose failures, reason about key lifecycles, and plan post-quantum migration.

The website is the main teaching surface. Colab notebooks supply executable experiments; Markdown lessons supply explanations and discussion prompts.
