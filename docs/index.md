## Learning path

1. [Day 1 — Applied Cryptography](day-1/index.md): security properties, AEAD, hashing, key derivation, public-key cryptography, signatures, and failure analysis.
2. [Day 2 — PKI, TLS and PQC](day-2/index.md): certificates, TLS, quantum risk, ML-KEM, hybrid approaches, and ML-DSA.
3. [Day 3 — Architecture and Migration](day-3/index.md): key management, trust boundaries, crypto agility, and migration.
